Open data · Pakistan

Hijri calendar and prayer times, as JSON

Confirmed Hijri month starts with sources, projected dates with explicit confidence, and calculated prayer times. No account, no key, no backend.

Read this first: treat any date whose confidence is not confirmed as approximate. It is not the committee's decision.

Base URL
https://pakistan-hijri.github.io/hijri-api

Quick start

const base = "https://pakistan-hijri.github.io/hijri-api";

const index = await fetch(`${base}/hijri/index.json`).then(r => r.json());
const calendar = await fetch(`${base}/hijri/calendar/1448.json`).then(r => r.json());

console.log(index.confirmed_through);
console.log(calendar.days["2026-11-12"]);

All routes are GET and served with access-control-allow-origin: *.

Routes

PathReturns
/hijri/index.jsonCoverage, generation time, Hijri years, confirmed-day count
/hijri/overrides.jsonConfirmed month starts and source URLs
/hijri/calendar/1448.jsonGregorian date → Hijri date, day number and confidence
/prayer/karachi/sunni_hanafi/2026.jsonDaily calculated prayer times

Replace 1448, 2026, city and profile as needed. Cities: karachi, lahore, peshawar, quetta. Profiles: sunni_hanafi, sunni_asr1, shia_jafari.

coverage_start is the first confirmed start. confirmed_through is the last published confirmed day. uncertainty_days: 2 appears on predicted days as a documented allowance, not a probability.

Confidence

LevelMeaning
confirmedInside a month whose start is verified in overrides.json.
estimatedA month start inferred in a gap between non-adjacent confirmed starts.
predictedA month start projected after the last confirmed start.
unconfirmedOnly a 30th day whose successor start is not confirmed.

Show ~9 Feb (estimated) and say the date is awaiting an announcement. Do not present it as fact.

TypeScript client

import { HijriCalendar, PrayerTable, hijriDate, sehriIftar } from "hijri-api";

const json = (path) => fetch(`https://pakistan-hijri.github.io/hijri-api${path}`).then(r => r.json());
const calendar = HijriCalendar.fromJSON(await json("/hijri/calendar/1448.json"));
const prayer = PrayerTable.fromJSON(await json("/prayer/karachi/sunni_hanafi/2026.json"));
const date = "2026-11-12";

const noon = hijriDate(new Date(`${date}T12:00:00+05:00`), { calendar });
console.log(noon.hijri, noon.confidence);

const maghrib = prayer.maghrib(date);
if (maghrib !== undefined) {
  const evening = hijriDate(new Date(`${date}T20:00:00+05:00`), {
    calendar, afterMaghrib: true, maghrib,
  });
  console.log(evening.hijri);
}

const fast = sehriIftar(prayer, noon.gregorian, noon);
if (fast !== undefined) console.log(fast.sehriEnds, fast.iftar);

hijriDate uses the midnight-based date by default. afterMaghrib needs that day's Maghrib. sehriIftar returns a value only during Ramadan.

Prayer times are calculated, not observed. For guidance only; defer to your local mosque or imambargah.
